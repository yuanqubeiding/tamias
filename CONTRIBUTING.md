# Contributing

> [中文版](CONTRIBUTING.zh.md)

Thanks for your interest in 栗栗 (Tamias). This is a personal project maintained with limited time and love, so every bit of feedback is genuinely appreciated.

## Ways to contribute

1. **Report a bug** — use the "Bug report" issue template and include your environment and reproduction steps
2. **Suggest a feature** — use the "Feature request" template and explain what you want and why
3. **Improve code / docs / translations** — open a pull request (see below)
4. **Fix docs or translations** — the bilingual README, legal docs, and translations all welcome fixes

## Before opening an issue

- Search existing issues first — avoid duplicates
- For bugs, include: OS version, 栗栗 version, reproduction steps, and logs (the in-app "Export logs" bundles them for you)
- State clearly what you expected vs. what actually happened

## Pull request workflow

1. Fork this repository
2. Create a branch that says what it does (e.g. `fix-xxx` / `feat-xxx`)
3. Make your change; keep comments in Chinese and match the surrounding style
4. Verify it locally
5. Use the PR template to describe what / why / how-tested
6. Open the PR — the author will review it

## Code style

- Comments in Chinese
- Put changes in the file whose responsibility matches; don't dump everything into `chat_dialog.py` (it's already overweight)
- Skim CHANGELOG and the existing architecture before starting, to avoid reinventing wheels

## Code of conduct (short version)

Be kind, be specific, critique the work not the person; no spam, no personal attacks.

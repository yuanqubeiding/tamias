# 栗栗（Tamias）隐私政策

**版本：v1.0　|　生效日期：2026-09-15**

本政策说明栗栗（Tamias）桌面智能助手（下称「本软件」）如何处理你的个人信息。**本软件的核心原则是「本地运行、最小收集、不上传」**，请放心阅读。

## 一、我们是谁

本软件由「栗栗（Tamias）桌面智能助手」的开发者（下称「作者」）提供。

**作者识别方式：GitHub github.com/yuanqubeiding。**

## 二、我们收集哪些信息（以及不收集什么）

本软件为**本地运行**的桌面应用，绝大多数数据仅存储在**你自己的设备**上，**不主动上传**至作者服务器。具体如下：

### 存储在你本地设备的信息

| 信息种类 | 内容 | 保存位置 |
|---|---|---|
| **对话内容** | 你输入的聊天内容、AI 的回复、历史对话记录 | 本地 `data/` 目录 |
| **API Key** | 你自己填写的第三方 AI 服务密钥 | 本地 `config.yaml` |
| **设置与偏好** | 语言、主题、模式等偏好 | 本地 `config.yaml` |
| **运行/崩溃日志** | 程序运行记录、错误信息 | 本地 `logs/` 目录 |

### 我们不收集、不保存、不传输的信息

- 我们**不收集、不保存、不上传**你的 API Key；
- 我们**不收集、不保存、不上传**你的对话内容；
- 我们**不收集、不保存、不上传**你的语音：语音输入采用本机（Windows）离线识别，你的说话声音仅在本地转成文字，音频不存储、不上传；转出的文字与「你手动输入的文字」同样处理；
- 我们**不收集**任何可用于直接识别你身份的信息（姓名、手机号、身份证号、精确位置等）；
- 我们**不使用 Cookie 或类似追踪技术**在本软件内追踪你的行为。

## 三、我们如何使用信息

上述信息**仅在本机本地**用于实现软件功能（聊天、干活、记忆、设置），我们：

- **不**将你的信息用于任何广告或营销；
- **不**向任何第三方出售、共享你的个人信息；
- **不**在作者服务器上存储你的对话或密钥。

## 四、信息如何传输给第三方

本软件**默认不向第三方传输你的信息**。唯一的例外是：

1. **调用第三方 AI 服务（如 DeepSeek）**：当你主动填写 API Key 并使用聊天/干活功能时，你**发送给 AI 的内容**会传输给你所选择的第三方服务提供商，由其按**该第三方的隐私政策**处理。本软件不中转、不存储这一过程，第三方如何处理你的内容由其自行负责。请你自行阅读并接受所选用第三方的隐私政策。
2. **查询天气（wttr.in）**：当你使用「查天气」功能时，本软件会把你填写的**城市名**（或留空时的公网 IP）发送至 wttr.in 天气服务，用于获取天气。该服务仅用于查询天气，不关联你的身份。
3. **主动导出日志**：当你主动点击「导出日志」时，本软件会把本地日志打包成文件，由**你自己**决定是否发送给作者（用于故障排查）。这一动作完全由你触发。

### 第三方组件清单

本软件集成或依赖以下第三方组件，其数据处理由各自权利人负责：

| 组件 | 用途 | 数据处理责任方 |
|---|---|---|
| DeepSeek 人工智能服务 | 聊天、干活 | DeepSeek |
| Node.js / DeepSeek Harness 运行时 | 干活引擎 | 各自权利人 |
| Live2D 及模型、字体（HarmonyOS Sans SC、Noto Sans JP、JetBrains Mono 等） | 立绘、界面显示 | 各自权利人 |
| wttr.in 天气服务 | 查天气 | wttr.in |

### 数据跨境说明

本软件**默认不进行数据跨境传输**，你的数据均存储于本地设备。唯一的例外是：你主动调用第三方 AI 服务时，你发送给该第三方的内容可能按该第三方的处理地点进行跨境传输，此行为由你主动发起，请自行阅读该第三方的隐私政策与跨境安排。

## 五、信息安全

1. 本软件本地运行，你的数据存储于你自己的设备，由你的操作系统安全机制保护。
2. 本软件不主动收集、不上传你的个人信息，因此**不存在作者服务器侧的数据泄露风险**。
3. 若发生涉及作者侧的数据安全事件（本软件原则上无作者侧数据），作者将依法在必要时予以告知。

## 六、保存期限

你的信息保存在**你自己的设备**上，由你自行控制：你可以随时删除本地 `data/` 目录、`config.yaml` 或卸载本软件，即可清除全部本地数据。我们不在任何服务器上留存你的信息。

## 七、你的权利

根据《中华人民共和国个人信息保护法》，你享有以下权利，且均可通过**本地操作**直接行使：

1. **查阅、复制、更正**：你的数据都在本地，可直接打开对应文件（如 `data/`、`config.yaml`）查看、编辑、复制。
2. **删除**：删除本地 `data/` 目录或卸载本软件，即完成删除。你也可随时请求作者协助，作者将配合。
3. **撤回同意**：你可随时停止使用并卸载本软件。
4. **投诉举报**：通过 GitHub Issues 提交，作者将在 7 个工作日内反馈。

## 八、未成年人保护

本软件**不面向未成年人**，且**不主动收集**不满 14 周岁未成年人的个人信息。未满 18 周岁的用户应在监护人同意和指导下使用；未满 14 周岁禁止使用。若你发现未成年人提供了其个人信息，请联系作者予以删除。

## 九、政策更新

本政策更新时，我们将以适当方式（如软件内提示）予以告知；重大变更将进行显著提示。更新后的政策自发布之日起生效。

## 十、联系我们

如对本政策有任何疑问、意见或投诉，请通过 **GitHub Issues** 提交。

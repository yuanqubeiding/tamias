# Tamias User Guide

Hi, I'm **Tamias**~ your squirrel detective butler living on your desktop. This guide gets you started in 3 minutes.

## 1. How to interact with me

- **Left-click me**: open the chat window and talk to me.
- **Right-click me**: pop up the menu (Settings / Library / User Guide / Export Logs / Quit).
- **Drag me**: move me anywhere on your desktop.
- I occasionally pop a little bubble above my head to greet you; poking me also gets a reaction.

## 2. Casual chat

- Click "💬 Casual Chat" to chat with me; what we say is saved automatically.
- I remember what we've talked about and pick it up next time.

## 3. Let me do work for you (Pro mode)

This is what I'm really good at — like a little assistant operating your computer.

1. How to open: right-click → Settings → check "⚡ Pro mode".
2. Click "📂 Open Folder" and pick a folder as your "project".
3. Then just tell me in plain words, e.g.:
   - "Convert all the images in this folder to png"
   - "Add a copyright line to the end of every .txt file"
4. Before I act, I'll first show you a "plan" — **every step needs your approval** before it actually runs. That's the "approval gate".

### What Tamias can do for you

In one sentence: **most "repetitive, tedious, back-and-forth-between-programs" computer work can be handed to me.** A few things I'm actually good at:

- **Organize / manage files**: classify, batch rename, find duplicates, list, count.
  - "Sort the 200 photos in the Downloads folder by date taken"
  - "Find the duplicate files in this folder"
- **Write automation scripts**: turn repeated manual work into a one-click script.
  - "Write a script to replace spaces with underscores in all .txt filenames in this folder"
- **Read documents / extract info**: read long documents down to the key points.
  - "List the amounts and dates in this contract"
  - "Summarize what this PDF says in three sentences"
- **Operate the computer**: open programs, create folders, move files, find where a file is.
  - "Create a folder called 'Work' on my desktop"

**Things I'm not good at** (telling you upfront so you don't wait and find out I can't):

- Sending emails, making PPT / posters / images — I don't have those tools, and the results would be ugly.
- Transactions involving money, or logging into your accounts and passwords — these you must do yourself.

### How the approval gate works

- I list a plan → you click "Approve" or "Reject".
- When unsure: **better to reject**, or first ask me "what will this step change".
- Rule of thumb: only approve operations you fully understand and are sure are harmless.

### Mistakes can be rolled back

- I automatically "snapshot" files before every change.
- On the right side of Pro mode there's "View recent changes" — compare before/after side by side, undo with one click.

## 4. Skins / characters

- Right-click → Library, click a persona to switch; it takes effect after restarting Tamias.

## 5. Settings

- Right-click → Settings, where you can change: Language / API Key / Pro mode / theme / always-work.

## 6. What to do when something breaks

- Right-click → "Export Logs" packs logs into a zip on your desktop; follow the prompt to send it to the author — that's fastest.
- Contact the author: GitHub Issues (github.com/yuanqubeiding)

## 7. FAQ

- **What is the API Key and where do I get it**: my chat and work rely on DeepSeek's brain. Go to platform.deepseek.com → sign up → API Keys → create → copy-paste into "Settings → API Key".
- **Do I need to install anything for work**: No. The "work" engine is bundled with the software, works out of the box; not working doesn't affect chatting.
- **Which operations should I approve**: only approve what you're sure is harmless and understand the consequences of; be extra careful with deleting files, changing system settings, and installing things.

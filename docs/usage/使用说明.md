# 栗栗使用说明

你好，我是**栗栗**～住在你桌面的松鼠侦探管家。这份说明带你 3 分钟上手。

## 一、怎么和我互动

- **左键点我**：打开聊天窗口，跟我说说话。
- **右键点我**：弹出菜单（设置 / 资源库 / 使用说明 / 导出日志 / 退出）。
- **拖着我**：把我挪到桌面任意位置。
- 我偶尔会从头顶冒个小气泡跟你打招呼，戳我也会回应。

## 二、日常闲聊

- 点「💬 日常闲聊」就能跟我聊天，说过的话会自动帮你存下来。
- 我会记住我们聊过的事，下次接着聊。

## 三、让我帮你干活（专业模式）

这是我真正的本事——像有个小助手帮你操作电脑。

1. 打开方式：右键 → 设置 → 勾选「⚡ 专业模式」。
2. 点「📂 打开文件夹」，选一个文件夹作为「项目」。
3. 然后直接用大白话吩咐我，比如：
   - 「把这个文件夹里的图片都转成 png」
   - 「给每个 .txt 文件末尾加一行版权」
4. 我动手前会先把「计划」列给你看，**每一步都要你点头批准**才会真的执行——这叫「门禁」。

### 栗栗能帮你做什么

一句话：**凡是「在电脑上重复、琐碎、要来回开程序」的活，大多能交给我。** 我实际擅长的几类：

- **整理 / 管理文件**：分类、批量重命名、找重复、列清单、统计数量。
  - 「把下载文件夹里 200 张照片按拍摄日期分好类」
  - 「找出这个文件夹里重复的文件」
- **写脚本自动化**：把要反复手动做的活写成一键脚本，以后点一下就行。
  - 「写个脚本，把这个文件夹里所有 .txt 文件名里的空格换成下划线」
- **读文档 / 提取信息**：把长文档读薄、挑出重点。
  - 「把这个合同里的金额和日期列出来」
  - 「总结一下这个 PDF 讲了什么，三句话」
- **操作电脑**：开程序、建文件夹、挪文件、查文件在哪。
  - 「帮我在桌面建一个叫『工作』的文件夹」

**这些我不太会**（提前说清，省得你等我做了才发现做不好）：

- 发邮件、做 PPT / 海报 / 图片——我没有这些工具，做出来也难看。
- 涉及钱的交易、登录你的账号密码——这类必须你亲自来。

### 门禁怎么用

- 我列计划 → 你点「批准」或「拒绝」。
- 拿不准时：**宁可拒绝**，或先问我「这一步会改什么」。
- 原则：只批准你完全明白、确定无害的操作。

### 干错了能回滚

- 我每次改文件前都会自动「拍照」留底。
- 专业模式右侧有「查看最近改动」，可以左右对比改前 / 改后，一键撤销。

## 四、换皮肤 / 换角色

- 右键 → 资源库，点选人设即可切换，重启栗栗后生效。

## 五、设置

- 右键 → 设置，可以改：语言 / API Key / 专业模式 / 主题风格 / 是否始终干活。

## 六、出问题了怎么办

- 右键 → 「导出日志」，会把日志打包成 zip 放到桌面，按提示提交给作者最快。
- 联系作者：GitHub Issues（github.com/yuanqubeiding）

## 七、常见问题

- **API Key 是什么、从哪来**：我聊天和干活要靠 DeepSeek 的大脑。到 platform.deepseek.com 注册 → API Keys 创建 → 复制粘贴到「设置 → API Key」。
- **干活要装什么吗**：不用装。我「干活」用的引擎已经随软件打包好，开箱即用；不干活也不影响聊天。
- **我该批准哪些操作**：只批准你确定无害、明白后果的；删文件、改系统设置、装东西要格外小心。
